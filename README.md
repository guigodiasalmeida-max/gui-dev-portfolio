# Brasa & Navalha — projeto conceitual integrado à GUI.DEV

Este projeto foi integrado ao portfólio em `projetos/brasa-navalha/`. É uma demonstração de design e desenvolvimento, não um negócio real. A marca, endereço, equipe, preços e horários são fictícios.

## Páginas incluídas
- `index.html` — página inicial
- `servicos.html` — serviços e preços demonstrativos
- `historia.html` — apresentação conceitual
- `equipe.html` — equipe fictícia
- `galeria.html` — galeria com filtros
- `agendamento.html` — formulário demonstrativo
- `contato.html` — contato e FAQ com dados fictícios
- `css/style.css` — estilos e responsividade
- `js/main.js` — navegação, menu e animações
- `js/booking.js` — demonstração de agendamento usando apenas o `localStorage` do navegador

## Como testar
Abra a pasta raiz `gui-dev-portfolio` no VS Code e execute o `index.html` com Live Server. No portfólio, selecione “Explorar projeto” no card Brasa & Navalha.

## Limitações importantes antes de publicar
- O agendamento apenas salva solicitações no navegador local. Não envia dados para uma equipe, não sincroniza dispositivos e não confirma reservas reais.
- Não há WhatsApp, telefone ou e-mail real configurado. Links com números fictícios foram removidos.
- O painel `admin.html` foi excluído da versão integrada porque não possui autenticação e não deve ser exposto como painel real. O ZIP original separado permanece intacto.
- Imagens e fontes são carregadas de serviços externos; é necessária conexão à internet.
- Substitua textos, imagens, endereço, equipe, preços e horários por informações autorizadas antes de adaptar este conceito para um cliente real.
- Para agendamentos reais, será necessário backend, validação de disponibilidade no servidor, autenticação apropriada, proteção de dados e política de privacidade.

## Tecnologias
HTML5 · CSS3 · JavaScript puro · localStorage (somente demonstração)
